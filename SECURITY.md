# Security

This repository serves a static website and public PDFs. There is no deployed chain and no funds are at risk here. Nothing described on the site is live.

- **Contact:** report privately through GitHub private vulnerability reporting on this repository: https://github.com/postfork/website/security/advisories/new (how it works: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability). No e-mail address is published yet. No response or disclosure timelines are promised yet.
- **Design soundness issues** (trust model, peg rules, attacks) concern the Postfork specification, not this website. Until the specification repository is public, report them privately through the same channel; never in a public issue. Once the specification repository is public, follow that repository's `SECURITY.md`.
- **Site issues** may be reported here: open redirects, mixed content, broken security headers, accidental indexing, or content that claims more than the specification (for example, describing anything as live).
