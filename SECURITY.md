# Security

This repository serves a static website and public PDFs. There is no deployed chain and no funds are at risk here. Nothing described on the site is live.

- **Contact:** no private channel is open yet. GitHub private vulnerability reporting (https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) is **not enabled** on this repository, and no e-mail address is published. This file will name the channel once it is enabled; a dedicated address on the planned domain `postfork.org` will be added once that domain is registered and mail is operational.
- **Design soundness issues** (trust model, peg rules, attacks) concern the Postfork specification, not this website. Do not open a public issue for an unpatched soundness flaw; keep the report until a private channel is named in this file, and once the specification repository is public, follow that repository's `SECURITY.md`.
- **Site issues** may be reported here: open redirects, mixed content, broken security headers, accidental indexing, or content that claims more than the specification (for example, describing anything as live).
